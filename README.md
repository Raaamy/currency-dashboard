# Wissel

Currency converter (EUR, USD, GBP, AED) with live bitcoin, gold and silver prices; installable PWA.

- Install: `npm install`
- Dev: `npm run dev`
- Test: `npm test`
- Build: `npm run build`
- Preview: `npm run preview`

See `docs/SPEC.md` (spec), `docs/PLAN.md` (tasks) and `docs/IOS.md` (iOS via Capacitor).
